# Mobile Funder dashboard refinement

## Outcome
Apply the selected compact, concierge-style mobile layout while preserving every existing Funder action and all funding behavior.

## Changes
- Compress the mobile identity area while keeping the profile picture and AI ID visible.
- Reduce the install notice’s mobile footprint so it no longer hides house browsing.
- Tighten mobile spacing around “Support tenants directly.”
- Keep houses with ready tenants first, retain the ready/vacant switch, and bring the first image-first house card into view sooner.
- Leave desktop layout, menu actions, routes, calculations, and financial flows unchanged.

## Validation
- Check the authenticated page at 390 × 844 and a narrow mobile width.
- Confirm no horizontal overflow or text overlap.
- Confirm profile, AI ID, top-right menu, ready/vacant switch, first house image, and existing menu actions remain available.
- Run the project guards and verify the preview build.
