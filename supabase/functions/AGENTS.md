# Database decisions: calling reports (read before changing these functions or the client code that reads them)

- Every call a Calling Center staff member made or took in a week (Calling Center attempts and received calls, Rent Plan pipeline awareness calls, Landlord Ops verification phone calls, app voice calls and the earlier tenant and landlord call logs) comes only from `cc_weekly_all_calls_report(p_from, p_to)` (migration `20261022160000`; SECURITY DEFINER, STABLE, read-only, `search_path = public`; authenticated only, same staff gate as `cc_concern_handling_report`). The Kampala day, who was called and the app-voice de-duplication (a call is counted once: a record is dropped when a higher-priority one shows the same caller phoning the same person or Rent Plan within 15 minutes) are decided there and nowhere else; the screen and PDF only arrange its rows.
- The Landlord Ops Calling Center registry and queue configuration come only from `v_landlord_registry_all` and the shared `cc_*` engine (`cc_cycle_populations` codes `landlords_registry_all`, `landlords_never_called`, `landlords_active_plans`, `landlords_paid_30d`, `landlords_unverified`, `landlords_no_houses`, `landlords_not_called_30d/60d/90d`; `cc_filter_options` keys `region`, `district`, `registering_agent`; `cc_sort_options` keys `plan_rent_total`/`highest_rent_plan_value`, `last_called_at`/`oldest_call_first`, `registered_at`/`newest_registration`, `name`; landlord-only `cc_feedback_categories` codes `reached_ok`, `confirmed_payout_number`, `wants_more_tenants`, `complaint`, `payout_issue`, `not_landlord`, `wrong_number`; saved queues via `landlord_cc_saved_queues` and RPCs `landlord_cc_save_queue` / `landlord_cc_list_queues`; non-blocking round-robin caller split via `landlord_cc_assign_callers(p_cycle_id, p_staff_ids[])`; migration `20261023120000`, gated by `_landlord_cc_staff_ok()`). `v_landlord_registry_all` unions `landlords`, `user_roles` (`role = 'landlord'`, including disabled/flagged) and orphan landlord phones from `rent_requests`/allocations/payouts, deduplicating by linked `user_id` then normalized phone (`256XXXXXXXXX`, `normalize_landlord_phone_256`) and marking unclear matches `needs_review = true` without guessed merges; tenant populations, filters, sorts and reports are never modified. Test: `supabase/tests/landlord_calling_center.sql`; rollback: `supabase/rollbacks/20261023120000_landlord_calling_center_foundation.rollback.sql`.
- Landlord Calling Center reports (`landlord_cc_daily_summary`, `landlord_cc_weekly_report`, `landlord_cc_coverage`, `landlord_cc_staff_performance`, `landlord_cc_landlord_call_log`, `landlord_cc_concerns_report`, `landlord_cc_round_report`; migration `20261023150000` and `20261028110000`, STABLE SECURITY DEFINER, `_landlord_cc_staff_ok()` gate, read-only, `search_path = public`, granted to `authenticated` only) are the sole definition of landlord calling figures across Kampala days and Wednesday–Tuesday weeks, built on the owner-only helper `_landlord_cc_events_in_window` (which also includes non-voided `landlord_calls` / `v_landlord_calls_effective` from the Landlord Calling Hub) so daily, weekly, staff and paged call-log totals always reconcile (`void_reason IS NOT NULL` / `voided_at IS NOT NULL` excluded, phones masked unless `_landlord_cc_can_view_unmasked_phone()`). Never compute these figures in the browser or edit `cc_weekly_all_calls_report` / tenant report functions. Test: `supabase/tests/landlord_calling_reports.sql`, `supabase/tests/landlord_calling_hub_reports.sql`; rollback: `supabase/rollbacks/20261023150000_landlord_calling_reports.rollback.sql`, `supabase/rollbacks/20261028110000_landlord_calling_hub_reports.rollback.sql`.
- Staff Calling & Rent Plan Pipeline Feedback reports for the calling team (Jane, Winnie, Hanisha) and HR / Management come only from `staff_calling_detailed_report(p_from, p_to)` (migration `20261025140000` and `20261028110000`; STABLE SECURITY DEFINER, read-only, `search_path = public`, granted to `authenticated` only), unioning Tenant Ops Calling Center, Landlord Ops Calling Center, Landlord Ops Calling Hub (`landlord_calls` / `v_landlord_calls_effective`, `source = 'Landlord Ops - Calling Hub'`, `prio = 2`, voided excluded, unrecorded `landlord_call_dials` older than 24h counted in `excluded_reveals`), Inbound Calling Center calls, Rent Plan Pipeline Awareness Calls, Landlord Ops Verification & Review Feedback, Tenant Ops Review Feedback, In-App Voice Calls and direct call logs with 15-minute per-staff deduplication in Africa/Kampala time. Winnie and Hanisha receive only their own rows (`staff_id = auth.uid()`); Jane (team head) and HR / executive oversight roles receive all three staff members' rows for the General Team report and individual staff filtering. Test: `supabase/tests/landlord_calling_hub_reports.sql`; rollback: `supabase/rollbacks/20261025140000_staff_calling_detailed_report.rollback.sql`, `supabase/rollbacks/20261028110000_landlord_calling_hub_reports.rollback.sql`.
- The Landlord Calling Hub (`/landlord-ops/calling`, switched via `system_config.landlord_hub_new` / `welile:landlord_hub_new`, default on) calls, dial markers, 24-hour same-caller amendments, landlord card details, list statuses (`to_call`, `call_back`, `answered`, `not_answered`, `never_called`) and top-strip stats come only from `landlord_hub_list`, `landlord_hub_detail`, `landlord_hub_agents`, `landlord_hub_start_dial`, `landlord_hub_record_call`, `landlord_hub_amend_call` and `landlord_hub_stats` over the append-only `landlord_calls` / `landlord_call_amendments` tables (`v_landlord_calls_effective`), `landlord_call_dials` (20-minute dial lock) and `mv_landlord_hub_registry` (migrations `20261028100000` and `20261028190000`; SECURITY DEFINER, `search_path = public`, granted to `authenticated` only; `landlord_ops` or `operations` to record, `landlord_ops`, `operations`, `hr`, `coo`, `ceo`, `cfo`, `manager`, `super_admin` to read, else 42501; phone masking via `_landlord_cc_can_view_unmasked_phone()`). The hub's list is built only from real `landlords` records (and orphan payout phones), never from the `landlord` role. Never compute hub call counts, statuses or double-dial checks in the client. Test: `supabase/tests/landlord_calling_hub.sql`, `supabase/tests/landlord_calling_hub_real_landlords.sql`, `docs/landlord-hub/test-results.md`; rollout & rollback: `docs/landlord-hub/rollout.md`, `supabase/rollbacks/20261028100000_landlord_calling_hub_foundation.rollback.sql`, `supabase/rollbacks/20261028190000_landlord_calling_hub_real_landlords.rollback.sql`.
