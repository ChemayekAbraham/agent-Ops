# Doc 247 appendix: profile-name lookups that can send a null or non-uuid id (2026-10-28)

Each row is a `from('profiles').select('id, full_name…').in('id', X)` call where `X` is built from a column that can be null
(or from free text such as `general_ledger.linked_party`) with no filter. One null or non-uuid value in `X` makes Postgres refuse
the whole lookup (`invalid input syntax for type uuid: "null"`), so every name on that screen comes back blank.
Fix per site: `X = X.filter(isUuid)` using `src/lib/isUuid.ts`. Generated by a scan of `src/`, so verify each before editing;
rows marked with an empty definition are chunked or parameter-passed lists the scan could not trace.
The six sites already fixed (step 49) are not listed because they now filter.
